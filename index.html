Légende des indicateurs
Niveau technique requis
●○○○○1 — Grand public : drag & drop, prise en main en quelques minutes, aucune compétence technique.
●●○○○2 — Bases suffisantes : logique de base, formules simples, compréhension des workflows. Accessible à tout profil métier.
●●●○○3 — Profil intermédiaire : compréhension des APIs, logique conditionnelle, bases relationnelles. Profil ops ou power user.
●●●●○4 — Profil technique avancé : développeur ou ops expérimenté, maîtrise SQL/JSON, architectures applicatives.
●●●●●5 — Développeur confirmé : code natif requis (JS, Python…), configuration serveur, déploiement infrastructure.
Sécurité & souveraineté des données
●○○○○1 — Risqué : code IA non audité (vibe coding), failles potentielles. À proscrire pour des données sensibles ou clients.
●●○○○2 — Faible : SaaS US sans certification tierce. Acceptable pour des usages internes non critiques.
●●●○○3 — Standard : SaaS avec bonnes pratiques (SSL, chiffrement, SOC2). Niveau acceptable pour la plupart des PME.
●●●●○4 — Solide : hébergement EU, RGPD by design, certifications ISO 27001 ou SOC2 Type II. Recommandé pour les données client.
●●●●●5 — Maximum : hébergement France, certifications HDS ou SecNumCloud, code open source auditable. Secteurs réglementés (santé, défense, finance).
